## 1. NAVER WORKS 협업과 WORKS Drive

### 핵심 근거 문서

1. [메시지 소개](https://help.worksmobile.com/ko/use-guides/message/overview/)
   - 텍스트·사진·동영상·파일·설문·위치·템플릿·할 일 전송, 읽음 확인, 회수, 메시지방의 노트·일정·할 일·폴더 기능을 설명한다.
   - 연수에서는 빠른 소통과 즉시 확인이 필요한 업무의 도구로 설명한다.

2. [메시지 공지](https://help.worksmobile.com/ko/use-guides/message/check-message/notice/)
   - 메시지방 상단에 공지를 등록하고 확인·해제하는 방법을 안내한다.
   - 장기 보존용 게시판 공지와 단기 메시지방 공지를 비교할 때 사용한다.

3. [메일 소개](https://help.worksmobile.com/ko/use-guides/mail/overview/)
   - 업무용 메일, 파일 첨부, 수신 확인·발송 취소, 예약 발송, 리마인드, 보안 등급 등을 설명한다.
   - 일부 기능은 상품과 관리자 설정에 따라 제한될 수 있다.

4. [게시판 소개](https://help.worksmobile.com/ko/use-guides/board/overview/)
   - 공개 게시판과 멤버 게시판, 게시글·댓글, 필독 게시글, 권한 관리의 기본 구조를 설명한다.
   - 연수에서는 여러 구성원이 다시 찾아봐야 하는 공식 공지·자료 축적 공간으로 설명한다.

5. [드라이브 소개](https://help.worksmobile.com/ko/use-guides/drive/overview/)
   - 공용 드라이브와 내 드라이브, 업로드, 링크 공유, 권한, 검색, 공동 관리와 버전 복원을 설명한다.

6. [사진 및 파일 올리기](https://help.worksmobile.com/ko/use-guides/drive/upload-download/upload-photo-or-file/)
   - PC 웹·모바일 업로드, 폴더 업로드, 끌어놓기, 메일로 업로드, 파일당 제한을 설명한다.

7. [드라이브 탐색기 설치](https://help.worksmobile.com/ko/use-guides/drive/explorer/windows/install/)
   - Windows 탐색기에서 WORKS Drive를 가상 드라이브처럼 이용하는 방법과 관리자 권한·동기화 관련 주의점을 안내한다.

8. [WORKS Drive 공식 이용요금·상품 비교](https://naver.worksmobile.com/pricing/works-drive/)
   - 공개 상품의 공용 용량과 기능 차이를 확인하는 기준 페이지다.
   - 공개 상품 정보는 기관 전용 계약 조건과 다를 수 있으므로 연수 자료에서 기관 계정 용량의 근거로 직접 사용하지 않는다.

9. [메시지방 폴더 열기](https://help.worksmobile.com/ko/use-guides/message/group-folder/open-folder/)
   - 여러 명이 참여하는 메시지방에서 폴더를 열고 파일을 공동 관리하거나 `드라이브에서 보기`로 연결하는 방법을 설명한다.
   - 상품·관리자 설정과 공공용 환경에 따라 기능이 제한될 수 있다는 주의를 함께 표시한다.

10. [폴더 유형별 특징](https://help.worksmobile.com/ko/use-guides/drive/share/folder-comparison/)
    - 내 드라이브의 공유 폴더와 메시지방 폴더의 관리 주체·권한 차이를 설명하는 근거다.

### 연수에서 사용할 핵심 구분

| 기능 | 적합한 용도 |
|---|---|
| 메시지 | 빠른 확인, 짧은 질의, 즉시 전달 |
| 메일 | 공식적인 외부·내부 소통, 전달 이력 |
| 게시판 | 반복해서 찾아볼 공지, 자료와 정보 축적 |
| WORKS Drive | 파일 보관, 권한별 공유, 공동 자료 관리 |

### 확인 필요

- 사용자가 확인한 **센스쿨 NAVER WORKS 계정의 500GB**는 현재 공개 상품의 공통 표준 용량으로 표현하지 않는다.
- 슬라이드에는 `센스쿨 NAVER WORKS 계정 할당 용량 500GB`로 표시하고, 실제 계정의 `드라이브 > 사용 용량` 화면을 근거로 사용한다.
- 센스쿨에서 제공되는 WORKS Drive 환경은 사용자가 확인한 범위에 따라 `파일 업로드·보기·다운로드`로 설명한다. NAVER WORKS 공개 상품 전체의 편집 기능 범위를 일반화하지 않는다.
- Google 문서·시트·슬라이드의 온라인 편집·공동 작업이 필요한 경우는 Google Drive의 역할로 구분한다.
- 공공용 NAVER WORKS는 일부 기능이 제한될 수 있으므로 실제 SEN 계정 화면과 대조한다.

## 2. Google Drive

### 핵심 근거 문서

1. [Google Drive 사용 방법](https://support.google.com/drive/answer/2424384?hl=ko)
   - 파일·폴더 생성과 업로드, 내 드라이브, 검색, 세부정보, 공유와 Drive for desktop의 기본 흐름을 설명한다.

2. [Google Drive에서 파일 공유하기](https://support.google.com/drive/answer/2494822?hl=ko)
   - 뷰어·댓글 작성자·편집자 권한, 특정 사용자 공유와 링크 공유, 학교 계정의 외부 공유 제한 가능성을 설명한다.

3. [Google Workspace for Education 저장용량 개요](https://support.google.com/a/answer/10403871?hl=ko)
   - Education의 저장용량이 조직 전체의 공용 저장용량으로 관리되며 관리자가 사용자·그룹별 한도를 설정할 수 있음을 설명한다.

4. [Drive for desktop 설치](https://support.google.com/a/users/answer/13022292?hl=ko)
   - Windows 탐색기나 macOS Finder에서 Drive 파일을 열고 클라우드와 컴퓨터를 동기화하는 방법을 안내한다.

5. [Drive for desktop의 파일 스트리밍과 미러링](https://support.google.com/drive/answer/13401938?hl=ko)
   - 스트리밍은 로컬 공간을 적게 사용하고, 미러링은 로컬과 클라우드에 전체 사본을 보관한다는 차이를 설명한다.

6. [공유 드라이브에서 파일 저장·공유하기](https://support.google.com/drive/answer/7286514?hl=ko)
   - 공유 드라이브 파일이 개인이 아니라 팀에 남는 구조와 역할별 권한을 설명한다.

### 확인 필요

- **Google Drive 200GB**는 Google Workspace for Education의 보편적인 개인 기본 용량이 아니다.
- Google 공식 문서상 Education은 조직 단위 공용 저장용량을 제공하고 관리자가 개인별 한도를 설정할 수 있다.
- 따라서 슬라이드에는 `서울시교육청 계정 제공 기준 200GB`처럼 기관 제공 조건으로 표시하고, 실제 계정의 저장용량 화면 또는 기관 공지를 근거로 추가한다.

## 2-1. 서울시교육청 Microsoft 365·OneDrive

1. [클래스이음 — 서울시교육청 Microsoft 365 클라우드 서비스](https://o365.sen.go.kr/)
   - 서울시교육청의 학생·교사가 웹 오피스, 개인별 웹 저장 공간, OneDrive와 Teams를 이용하는 공식 지원 사이트다.
   - 연수에서는 `서울시교육청 Microsoft 365 협약 계정`의 공식 서비스 진입점으로 안내한다.

2. [서울시교육청 Microsoft 365 사용자 매뉴얼](https://o365.sen.go.kr/uploads/%ED%81%B4%EB%9E%98%EC%8A%A4%EC%9D%B4%EC%9D%8C_%EC%A3%BC%EC%9A%94%ED%99%94%EB%A9%B4_%EC%82%AC%EC%9A%A9%EC%9E%90.pdf)
   - 학교 검색, 학교별 가입 인증키, 교사·학생 계정 생성, 암호 재설정과 Microsoft 365 앱 설치 절차를 설명한다.
   - 정보부장 또는 Microsoft 365 담당자에게 확인할 것은 OneDrive 용량이 아니라 학교별 가입 인증키, 계정 발급·접속 방법과 계정 종료 전 자료 이관 절차다.

### 연수 적용 기준

- 사용자 확인에 따라 **서울시교육청 협약 계정의 OneDrive 제공 용량은 1TB**로 확정해 표시한다.
- 이를 일반 Microsoft 365 계정 전체의 보편적인 기본 용량으로 일반화하지 않는다.
- 역할은 `Word·Excel·PowerPoint 온라인 편집·공유`, `Windows 탐색기 연동`, `1TB 추가 저장공간`으로 정리한다.

## 2-2. Chrome 프로필과 동기화

1. [여러 프로필로 Chrome 관리하기](https://support.google.com/chrome/answer/2364824?co=GENIE.Platform%3DDesktop&hl=ko)
   - 개인·업무용 또는 사용자별로 북마크, 방문 기록, 비밀번호와 설정을 분리하는 근거다.
   - 공유 PC에서는 다른 사용자가 해당 기기의 Chrome 프로필을 열 수 있으므로 신뢰할 수 있는 기기에서만 프로필을 유지하도록 안내한다.

2. [모든 기기에 북마크, 비밀번호 등 가져오기](https://support.google.com/chrome/answer/165139?co=GENIE.Platform%3DDesktop&hl=ko)
   - 로그인한 기기에서 북마크·비밀번호·탭·방문 기록 등을 계정에 저장하고 다른 기기에서 이어 쓰는 기능의 근거다.
   - 연수에서는 ‘로그인’과 ‘업무용 프로필을 기기에 남기는 것’이 같은 판단이 아님을 강조한다.

3. [시크릿 모드로 탐색하기](https://support.google.com/chrome/answer/95464?hl=ko)
   - 모든 시크릿 창을 닫으면 Chrome이 사이트 데이터와 방문 기록을 보관하지 않지만, 다운로드한 파일과 저장한 북마크는 기기에 남는다는 근거다.
   - 공용 PC에서는 `Ctrl+Shift+N`으로 새 시크릿 창을 열고, 사용 후 모든 시크릿 창을 닫으며 다운로드 파일을 직접 삭제하도록 안내한다.

4. [Microsoft Edge에서 InPrivate 찾아보기](https://support.microsoft.com/ko-KR/edge/browse-inprivate-in-microsoft-edge)
   - 모든 InPrivate 창을 닫을 때 검색 기록·쿠키·사이트 데이터·암호·양식 데이터 등을 지우지만, 즐겨찾기와 다운로드 파일은 남는다는 근거다.
   - 시크릿/InPrivate 브라우징은 학교·직장·인터넷 서비스 제공자에게 활동을 숨기는 익명 기능이 아니라는 제한도 함께 안내한다.

## 3. 수업 화면 공유와 Windows 중계

   - Windows 근거리 공유가 Bluetooth 또는 Wi-Fi를 이용해 지원되는 Windows PC끼리 문서·사진·링크를 보내는 기능임을 설명한다.
   - Android·iPhone의 기본 근거리 파일 전송 규격과 직접 호환되는 기능으로 설명하지 않는다.

2. [Android와 Windows 간 Quick Share](https://support.google.com/android/answer/13801258?hl=ko)
   - Android와 Windows 사이에서 사진·동영상·문서를 주고받는 설치 방법, 기기 공개 범위, Bluetooth·Wi-Fi와 네트워크 조건을 설명한다.

3. [휴대폰과 연결을 통한 Android·Windows 파일 전송](https://support.microsoft.com/en-US/Windows/Apps/PhoneLink/seamlessly-transfer-content-between-your-devices)
   - 연결된 Android 기기와 Windows PC 사이에서 공유 메뉴로 파일을 전송하는 방법과 버전 조건을 설명한다.

4. [Windows 시작 메뉴의 모바일 장치 파일 보내기](https://support.microsoft.com/en-US/Windows/Apps/PhoneLink/mobile-device-in-start-menu)
   - 연결된 Android 또는 iPhone에 파일을 보내는 최신 Windows 11 기능을 설명한다.
   - 단계적으로 배포되므로 연수에서는 주 경로가 아닌 보조 정보로 표시한다.

### Windows와 Miracast

1. [Windows PC 또는 무선 디스플레이로 화면 미러링·투사](https://support.microsoft.com/en-us/windows/hardware/display-graphics/screen-mirroring-and-projecting-to-your-pc-or-wireless-display)
   - `Windows + K`로 Miracast 디스플레이에 연결하는 방법을 안내한다.
   - 다른 Windows PC가 화면을 받으려면 `무선 디스플레이` 선택적 기능을 설치하고 수신 앱을 실행해야 한다.
   - 송신·수신 기기의 Wi-Fi, Miracast 지원 여부와 Windows 버전을 사전에 확인해야 한다.
   - Windows 11 수신 PC의 공식 설치 경로는 `시작 > 설정 > 시스템 > 이 PC에 다른 화면 표시 > 선택적 기능 > 기능 보기 > 무선 디스플레이 > 다음 > 설치`다.
   - 설치는 Windows의 선택적 기능에서 진행하므로 연수 자료에서는 별도의 웹 설치 파일 다운로드 링크를 안내하지 않는다.
   - 설치 후 `이 PC에 다른 화면 표시`로 돌아가 수신 조건을 정하고, 작업 표시줄 검색에서 `무선 디스플레이` 앱을 실행한다.
   - `무선 디스플레이` 앱은 Windows 11 22H2 이상 기준이며, 이전 Windows에서는 `연결` 앱을 사용한다.

2. [Windows의 무선 디스플레이 또는 도크 연결 문제 해결](https://support.microsoft.com/ko-KR/Windows/hardware/display-graphics/fix-connections-to-wireless-displays-or-docks-in-windows)
   - Miracast 지원 여부, Wi-Fi, 대상 PC의 무선 디스플레이 앱 설치·실행, 드라이버와 수신기 펌웨어 업데이트를 점검하는 공식 문제 해결 문서다.
   - 학교 관리 PC에서 선택적 기능 설치가 차단되면 현장에서 우회 설치를 시도하지 않고 관리자 지원 또는 유선 연결로 전환한다.

3. [Windows 기기를 모바일 핫스팟으로 사용](https://support.microsoft.com/en-us/windows/experience/connectivity-networking/use-your-windows-device-as-a-mobile-hotspot)
   - Windows의 Wi-Fi·Ethernet·셀룰러 연결을 다른 기기에 공유하는 방법을 설명한다.
   - 학교망에서 기기 간 통신이 차단될 때 시험할 별도 네트워크 구성의 참고 자료로 사용한다.

   - Android와 Cast 수신 기기가 같은 SSID에 있어야 하며 AP 격리가 켜진 네트워크에서는 통신이 막힐 수 있음을 설명한다.

   - Galaxy의 Smart View로 호환 TV·모니터에 화면을 미러링하는 방법과 같은 Wi-Fi, 기기·모델별 지원 차이를 설명한다.

7. [AirPlay로 iPhone·iPad 화면 미러링](https://support.apple.com/ko-kr/102661)
   - Apple TV, AirPlay 호환 스마트 TV 또는 Mac으로 미러링하는 방법을 설명한다.
   - Windows PC는 Apple의 기본 AirPlay 수신 대상으로 안내되지 않으므로, 별도 수신 소프트웨어 없이 iPhone 화면을 Windows 무선 디스플레이로 받을 수 있다고 설명하면 안 된다.

### 파일 공유·연결 문제 해결용 보조 문서

8. [Quick Share로 Android와 Windows 간 파일 공유](https://support.google.com/android/answer/13801258?hl=ko)

   - Windows 근거리 공유는 지원되는 Windows PC 사이의 기능이라는 근거다. Android·iPhone 공통 공유 기능으로 소개하지 않는다.

### 확인 필요

- 전자칠판의 제조사·모델과 지원 프로토콜(Miracast, Google Cast, AirPlay)을 확인해야 직접 연결 방법을 확정할 수 있다.
- 학교 무선망의 AP 격리·VLAN·방화벽 정책에 따라 같은 Wi-Fi에 연결되어도 기기가 서로 보이지 않을 수 있다.
- Windows PC가 Miracast 수신을 지원하지 않거나 `무선 디스플레이` 기능 설치가 차단된 경우 교사 PC 중계 방식은 사용할 수 없다.

## 5. PowerToys와 ZoomIt

1. [Microsoft PowerToys](https://learn.microsoft.com/en-us/windows/powertoys/)
   - 무료 오픈 소스 Windows 유틸리티 모음이며 ZoomIt, Mouse Utilities, Text Extractor, Always On Top, Awake 등이 포함된다는 공식 근거다.

2. [PowerToys 설치](https://learn.microsoft.com/en-us/windows/powertoys/install)
   - Microsoft Store, Microsoft 공식 GitHub, WinGet을 통한 설치 방법과 지원되는 Windows 환경을 설명한다.
   - 학교 관리 PC에서는 관리자 정책으로 설치가 제한될 수 있으므로 임의 우회를 안내하지 않는다.
   - 연수 슬라이드 설치 링크:
     - Microsoft Store: <https://aka.ms/getPowertoys>
     - Microsoft 공식 GitHub 최신판: <https://aka.ms/installpowertoys>

3. [ZoomIt](https://learn.microsoft.com/en-us/windows/powertoys/zoomit)
   - 확대 `Ctrl+1`, 확대 없이 그리기 `Ctrl+2`, 실시간 확대 `Ctrl+4`, 녹화 `Ctrl+5`의 기본 단축키와 설정 방법을 설명한다.
   - 최신 PowerToys에 포함되며 Sysinternals 독립 실행판도 계속 제공된다.
   - Sysinternals 독립 실행판 안내·다운로드: <https://learn.microsoft.com/sysinternals/downloads/zoomit>

4. [Mouse Utilities](https://learn.microsoft.com/en-us/windows/powertoys/mouse-utilities)
   - `Ctrl` 두 번으로 Find My Mouse를 실행하고 `Win+Shift+H`로 Mouse Highlighter를 켜는 기본 사용법을 설명한다.

5. [Text Extractor](https://learn.microsoft.com/en-us/windows/powertoys/text-extractor)
   - `Win+Shift+T`로 화면 영역의 글자를 OCR해 클립보드에 복사하며, 결과에 오류가 있을 수 있어 검토가 필요하다고 안내한다.

6. [Always On Top](https://learn.microsoft.com/en-us/windows/powertoys/always-on-top)
   - `Win+Ctrl+T`로 활성 창을 다른 창 위에 고정하거나 해제하는 기능을 설명한다.

7. [Awake](https://learn.microsoft.com/en-us/windows/powertoys/awake)
   - 전원 계획을 영구 변경하지 않고 PC 또는 화면이 자동으로 꺼지지 않게 할 수 있으며, 잠금 화면에서는 작동하지 않는다는 제한을 설명한다.
