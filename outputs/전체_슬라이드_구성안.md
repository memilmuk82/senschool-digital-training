# 학교로 찾아가는 디지털 직무연수 - 센스쿨 활용 — 90분 수업 구성안

- 버전: 50분 연수 + 10분 휴식 + 50분 연수 운영안
- 기준일: 2026-08-24
- 단계: 전체 슬라이드 구성 승인 완료 · 화면 자산 보완 및 제작 대기
- 아직 하지 않는 작업: HTML 슬라이드 제작, 캡처 강조 표시, 세부 문장 다듬기
- 제작 순서: 본문과 마무리 내용을 먼저 확정하고, 표지·사전 설문 등 도입부 슬라이드는 마지막에 제작한다.

## 1. 연수의 한 문장

**교사가 여러 서비스의 기능을 외우는 대신, 자료를 보관·공유하고 다른 기기의 화면을 연결하며 반복 업무를 SenGPT로 줄이는 흐름을 익힌다.**

## 2. 범위 결정

### 이번 연수에 포함

1. Chrome 업무용 프로필과 동기화
2. NAVER WORKS 메시지·메일·게시판·WORKS Drive
3. Google Drive 200GB, WORKS Drive 500GB, 서울시교육청 Microsoft 365 협약 계정의 OneDrive 1TB와 역할 구분
4. 파일 전송, 화면 공유, 인터넷 공유의 차이
5. Windows 근거리 공유, Quick Share, Miracast, 무선 디스플레이, Cast, Smart View, AirPlay, 모바일 핫스팟
6. SenGPT 나만의 에이전트, 대화 예약, 워크플로우
7. [선택] Windows 캡처 도구의 확장 기능, 교사용 단축키, 25H2·최근 업데이트의 주요 변화
8. [선택] PowerToys의 ZoomIt과 교사용 보조 기능

### 이번 과정에서 제외

- 전자칠판 제조사별 전용 기능 소개
- 전자칠판 판서·수업 장면 실습
- 모든 참여자가 동시에 전자칠판에 연결하는 실습
- Padlet·Canva 기능 실습

Padlet과 Canva는 부록에서 `Drive 자료 → Canva 가공 → Padlet 참여 수합`의 후속 연계만 보여 준다. 현재 핵심 범위에 추가하면 협업·연결·SenGPT 중 하나를 줄여야 한다.

### 연수 중 실습은 세 개만 운영

| 실습 | 참여자가 하는 일 | 운영 원칙 | 연결 슬라이드 |
|---|---|---|---:|
| 저장·공유 판단 | 상황 카드를 보고 Google Drive / WORKS Drive와 공유 권한을 고른다 | 로그인 없이 선택과 이유만 확인 | 15 |
| 화면 연결 판단 | 자신의 기기 조합에서 직접 연결 / 교사 PC 중계 / 별도 네트워크 중 하나를 고른다 | 실제 동시 연결 대신 호환표에 경로를 표시 | 27 |
| SenGPT 실행·검토 | 제공된 프롬프트 틀에서 `주제·공식 출처·결과 형식`만 바꾸고 한 번 실행한 뒤 결과를 점검한다 | 프롬프트를 처음부터 쓰거나 에이전트를 각자 새로 만들지 않음 | 33~35 |

SenGPT 실습에서 **하네스**는 역할·입력 범위·성공 기준·출력 형식을 고정하는 틀로, **루프**는 `검색 → 출처·날짜 검증 → 부족하면 재검색 → 최종 점검`의 반복 절차로 설명한다. 긴 프롬프트 작성법 강의는 제외하고, 완성된 틀의 일부만 바꾸게 한다.

## 6. 무선 디스플레이 설치 슬라이드의 확정 내용

### Windows 11 설치 경로

1. `설정 > Windows Update > 업데이트 확인`으로 먼저 최신 상태를 점검한다.
2. `설정 > 시스템 > 이 PC에 다른 화면 표시`를 연다.
3. `선택적 기능 > 기능 보기`를 선택한다.
4. `무선 디스플레이`를 검색해 선택하고 `다음 > 설치`를 누른다.
5. 설치 후 `이 PC에 다른 화면 표시`로 돌아가 수신 조건을 정한다.
6. 작업 표시줄 검색에서 `무선 디스플레이` 앱을 실행해 연결 대기 화면을 연다.

### 슬라이드에 붙일 주의사항

- 웹사이트에서 별도 설치 파일을 받는 기능이 아니다. Windows의 `선택적 기능`에서 설치한다.
- 선택적 기능 다운로드에는 인터넷 연결과 Windows Update 서비스가 필요하다.
- 학교 관리 PC에서는 관리자 정책으로 설치가 제한될 수 있다. 현장에서 임의 우회를 시도하지 않는다.
- Windows 11 22H2 이상은 `무선 디스플레이` 앱을 사용하고, 이전 Windows에서는 `연결` 앱이 표시될 수 있다.
- 설치 후에도 송신·수신 장치의 Miracast 지원 여부와 Wi-Fi 상태를 별도로 확인해야 한다.
- 공식 안내: <https://support.microsoft.com/ko-KR/Windows/Hardware/Display-Graphics/screen-mirroring-and-projecting-to-your-pc-or-wireless-display>

## 8. 화면 자료 사용 원칙

1. 공식 화면으로 개념을 설명하고 실제 계정 화면으로 위치를 확인한다.
2. 전체 화면보다 필요한 메뉴·대화상자만 사용한다.
3. 캡처에는 표시를 굽지 않고 HTML 슬라이드에서 투명 면과 빨간색 약 2mm 테두리를 올린다.
4. 한 슬라이드의 강조 영역은 1~3개만 둔다.
5. NAVER WORKS 테스트 메시지·메일은 본인 대상 화면만 사용한다.
6. 삭제된 게시판 테스트 글의 캡처는 기능 설명용으로만 쓰며 실제 게시글이 남아 있다고 표현하지 않는다.
7. Google Drive 200GB와 WORKS Drive 500GB는 `서울시교육청/기관 계정 제공 기준`으로 표시한다.
8. 서비스 화면과 기능은 바뀔 수 있으므로 모든 관련 슬라이드에 `화면 확인: 2026-08-24`를 표기한다.
9. 슬라이드에는 권장 소요 시간, 제한 시간, 남은 시간 또는 휴식 타이머를 표시하지 않는다.
